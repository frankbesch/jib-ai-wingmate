## H2. Controls, scorer, audit builder (new files in `heldout2/`, tests in `heldout2/tests/`)
`controls.py` (pure functions, no I/O beyond reading a run folder; this file gets frozen by hash):
- `doc_class(month)`: class per doc_id as the document parser assigned it. Determine from `month.json` which key is the document parser's own output (`classify[].predicted` vs `documents[].class`) and document the choice in the docstring. Never read the corpus manifest.
- `norm(s)`: strip, collapse internal whitespace to one space, casefold. Nothing else.
- `bounded_in(needle, hay)`: normalised needle occurs in normalised hay with a non-alphanumeric character or the text edge on both sides.
- K1 `k1_flags(units, month)`: flag a row-8 unit whose final answer is False (not printed), not abstained, and whose field is in `REQUIRED[class]` from `reconcile.py` (parse the literal from source with `ast`; do not import or execute reconcile.py).
- K2 `k2_flags(units, month, texts, drop_source=None)`: sources = `values.afe_number` of every document whose parser class is `afe` or `afe_cover` in the same run; a source that is None, empty, or under 3 characters after `norm` is no source; flag an `afe_number` unit whose final answer is False, not abstained, when any source is `bounded_in` that document's text. `drop_source=<doc_id>` removes one source document (source-loss check).
- K3 `k3_flags(units, reference_doi, texts)`: same match for fields `well_name`, `owner_name`, `owner_number`, `property_number` with sources from `reference/doi.json`; inspect `synth-heldout/reference/doi.json` and freeze an explicit key mapping in a module constant; a field with no matching key is skipped and reported.
`score_heldout2.py --corpus synth-heldout2 --run-clean runs/<id> --run-scan runs/<id> [--audit ...] --out <json>`: computes, per set and per base cascade repeat, exactly the definitions and marks P1 to P6 and Overall in plan section 6 (read it closely: target errors per repeat, a catch must be in the same repeat, unique targets with packet and label variant from `cases.json`, INCONCLUSIVE rules, P2 decided on K1+K2 with K1-only and K2-only printed, unique items to a person counted once, P3 per case class with the zero-flag condition for classes whose `cases.json` entry has `flag_would_be_false_alarm: true`, source-loss table, layer A and layer B truth side by side, per-packet table, exclusion sensitivity bounds). Emits JSON and a markdown table. Arm discovery by out-dir tag (base C vs alias vs batched, from H1's tag; coordinate the tag strings: alias runs contain `-alias-afe_number`, batched runs contain `-c8-per-document`).
`make_audit2.py`: adapt `synth-heldout/tools/make_audit.py`. Primary audit set per plan section 6: every unit any A, B, or base C run missed plus a random 40 that all of those got right (seed constant `AUDIT_SEED = 20261002`), page images in randomised order, and a BRIEF with the field definitions and the three field-presence semantics from plan section 3 and NO worked example and NO answers. A second, separate set for units only alias or batched runs missed.
Tests: synthetic fixtures for every rule and mark edge (zero targets, catch in a different repeat does not count, source missing, bounded match negatives like `DB-26-9011` vs `DB-26-901`, case and spacing). Also a smoke run of K1 and K2 on run 1's folders (allowed: run 1 is already seen) printing counts.

## H3. Orchestration (new files `heldout2/run_heldout2.py`, `heldout2/run-heldout2.sh`, tests in `heldout2/tests/`)
One Frank-started command runs every stage in order; plan sections 2, 7, 8, 9 are the contract. Python does the work; the `.sh` is a thin launcher that checks the two keys exist in the environment by length only (never prints them), checks `claude -p` sign-in, and execs python.
Stages, each with a deadline and one retry (plan section 9 table): critic -> designer -> generator (build + layer A key + gates) -> blind re-key -> compare and adjudicate (third session per R6) -> parser clean, parser scan (`pipeline.py --mode live --corpus synth-heldout2 --variant ...`) -> make_layerb per set -> layer B key per set -> freeze hashes -> arms per set in this order: A x2, B x3, C x2, B-alias x1, C-alias x2, A-batched x2 (through `typed/run-typed-redo.sh ... --yes`; check how its repeats, tags, and receipts work) -> make_audit2 -> audit sessions -> adjudicate -> score.
Requirements:
- `--stub`: every external command (codex, pipeline live, run-typed-redo live) replaced by a fast fake that writes plausible outputs, so the whole chain, the ledger, stop, and resume can be proven with no network and no spend. `--dry-run` prints the stage list with commands and deadlines.
- Codex sessions (R4): each runs in a fresh folder `runs/heldout2/<stamp>/sessions/<stage>/` holding copies of its permitted inputs only (the brief in `heldout2/briefs/<stage>.md` plus the inputs that brief's header lists under `INPUTS:`), launched as `codex exec --skip-git-repo-check -s workspace-write -C <folder> "<brief text>" </dev/null` with an environment stripped of every variable whose name contains KEY, TOKEN, or SECRET. The session log is saved. After the session, scan the log for any command that reads a path outside the session folder (absolute paths not under the folder, or `..` escapes); a hit marks the stage INVALID and stops. Record prompt hash, input hashes, and `~/.codex` instruction files present. Outputs are copied out to the corpus folder by the script, not by Codex.
- Ledger (R5): `ledger.json` persists parser credits (cap 800) and Jev dollars (cap 0.50) across stages, retries, and resumes; a call of unknown outcome counts as spent at its bound; the script refuses to start a stage whose bound would pass a cap.
- Checkpoints and resume (R9): each finished stage writes input and output hashes; `--resume <stamp>` verifies them, skips valid finished stages, never re-submits a completed call of a still-valid run; retry counters persist; R7/R8 whole-stage or whole-run retries are deliberate and exempt.
- Failure policy: R6 (more than 10 excluded units per set -> INVALID stop), R7, R8 (a failed arm run is moved to a quarantine folder and rerun whole once), R11 (stop on a usage-limit message from `claude -p`; do not wait).
- Deadlines: kill the stage's process group at its deadline; that counts as a failure.
- Status: one line per stage appended to `status.log`; secrets never written anywhere.
- Hash freeze of `heldout2/controls.py`, `score_heldout2.py`, `make_audit2.py`, the briefs, and the alias constant happens at the very start and is verified before scoring; a mismatch stops the run.
Tests: stub end-to-end run; a forced stop then `--resume`; a cap refusal; an out-of-folder read detected in a fake session log; a deadline kill.
